# Map Mates

## Setup

In order to set up the project you need to install three sets of dependencies.

Run `npm i` in the root (for TypeScript), in `./client/`, and in `./server`.

## Run the Server
Once dependencies are installed, navigate to `server/` and execute `npm start`. You'll know it's up once you see:
```
Your routes will be running on http://localhost:3000
```

## Run the Client
On a fresh install or after making some changes, first run `npm run build`. This will be read during execution.

Once built, run `npm start` to start the sever. You'll be able to access the server from http://localhost:5173/.
